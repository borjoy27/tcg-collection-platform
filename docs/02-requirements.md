## 3. 기능 요구사항
플랫폼 핵심 기능 요구사항 정의 및 개발 진행 현황 관리

| 총 기능 수 | 진행 중 | 완료 | 전체 진행률 |
|---|---|---|---|
| 25 | 0 | 0 | 0.0% |

| 대분류 | 기능명 | 상세 기능 설명 | 진행 상태 |
|---|---|---|---|
| 1. 회원 및 권한 관리 | 간편 회원가입 | 외부 소셜/플랫폼 계정 연동을 통한 빠른 가입 처리 | 예정 |
| 1. 회원 및 권한 관리 | 권한별 이용 범위 | 비회원은 카드 예상 등급 산출 및 가품 의심 여부 확인만 가능, 회원은 도감·위시 리스트·교환·판매·통합 제안·마이페이지 전체 이용 가능 | 예정 |
| 2. 카드 예상 등급 및 진위 분석 | 다중·단일 카드 인식 | 카메라 촬영 또는 갤러리 선택을 통한 1장/복수 카드 영역 인식 | 예정 |
| 2. 카드 예상 등급 및 진위 분석 | 예상 등급 산출 | 카드 상태(모서리·표면·센터링 등) 기반 예상 등급 제공 | 예정 |
| 2. 카드 예상 등급 및 진위 분석 | 가품 의심 여부 산출 | 인쇄·폰트·홀로그램/질감 등 시각적 특징 기반 가품 의심 신호 및 안내 제공 | 예정 |
| 3. 도감 관리 | 도감 등록 및 수량 반영 | 분석 완료 카드의 도감 등록 및 보유 수량 반영(신규 획득 시 보유 전환, 추가 획득 시 수량 증가) | 예정 |
| 3. 도감 관리 | 도감 조회 | 보유/미보유 카드 목록 및 상세 스펙 조회(카드팩명, 카드 번호, 종류, 카드명, HP, 타입, 기술, 약점 등) | 예정 |
| 3. 도감 관리 | 도감 검색·필터·정렬 | 포켓몬/트레이너스/에너지 구분 및 카드팩명, 종류, 타입, 저항력, HP, 후퇴 비용 등 조건별 검색·정렬 | 예정 |
| 3. 도감 관리 | 팩별 수집률 표시 | 카드팩별 등록 카드 비율(%) 시각화 | 예정 |
| 3. 도감 관리 | 위시 리스트 | 미보유 카드 즐겨찾기(하트) 등록 및 관리 | 예정 |
| 3. 도감 관리 | 거래 확정 연동 도감 동기화 | 거래 최종 완료 시 발송 카드 수량 차감(0장 시 미보유 전환) 및 수령 카드 도감 반영 | 예정 |
| 4. 교환 기능 | 상대 카드 상세 조회 | 교환 대상 카드의 이미지, 예상 등급, 가품 의심 여부 확인 | 예정 |
| 4. 교환 기능 | 위시 리스트 매칭 추천 | 서로의 위시 리스트 교집합을 기반으로 교환 후보 유저 추천 | 예정 |
| 4. 교환 기능 | 교환 조건 조율 및 배송 선택 | 채팅을 통한 실물 확인·조율 및 배송 방식 선택(일반 택배, 편의점 택배, 직거래) | 예정 |
| 4. 교환 기능 | 상호 보증금 예치·반환 | 양측 시세 기준 보증금 예치 후 상호 수령 확인 시 반환 | 예정 |
| 5. 판매 기능 | 판매 카드 조회 및 장바구니 | 판매자 카드 정보 확인, 동일 판매자 다건 카드 장바구니 담기 및 일괄 결제 | 예정 |
| 5. 판매 기능 | 즉시 구매(에스크로) 및 채팅 조율 | 별도 조율 없이 안전결제 즉시 구매 또는 채팅 조율 후 진행, 배송 옵션 선택(일반 택배, 편의점 택배, 준등기, 직거래) | 예정 |
| 5. 판매 기능 | 구매 확정 및 판매자 정산 | 구매자 수령 확인(또는 자동 구매 확정 기간 경과) 시 판매자 계좌로 정산 지급 | 예정 |
| 6. 통합 거래 제안 | 제안서 발송 및 역제안 | 채팅 내 [거래 제안서 카드] 생성 및 카드 구성·차액 현금 조건을 수정해 재전송하는 역제안 지원 | 예정 |
| 6. 통합 거래 제안 | 수락 시 카드 잠금 | 제안 수락 즉시 포함 카드 상태를 '거래 중(예약 중)'으로 잠가 중복 거래·제안 차단 | 예정 |
| 6. 통합 거래 제안 | 차액 에스크로 / 보증금 예치 | 현금 차액 발생 시 지불 측 에스크로 입금, 순수 맞교환 시 상호 보증금 예치 | 예정 |
| 6. 통합 거래 제안 | 운송장 등록 및 일괄 완료 | 양측 운송장 입력 및 수령 확인 완료 시 대금 정산·보증금 반환·도감 동기화 일괄 처리 | 예정 |
| 7. 마이페이지 및 운영 | 실거래가 시세 조회 | 플랫폼 내 완료 거래 데이터 기반 평균 시세 및 최근 거래 추이 제공(보증금 산정 기준 활용) | 예정 |
| 7. 마이페이지 및 운영 | 분쟁·반품 신고 | 수령 카드가 AI 분석/사진과 상이하거나 가품이 의심될 때 구매 확정 보류 및 반품/환불/정밀 검수 접수 | 예정 |
| 7. 마이페이지 및 운영 | 거래·정산 내역 및 신뢰도 평점 | 거래 이력, 에스크로 예치·정산 내역 조회 및 거래 완료 후 포장 상태·응답 속도 기반 신뢰도 지수(매너 온도 등) 평가 | 예정 |
